SkyTools.Linux

O SkyTools.Linux é apenas um port do SkyTools de Windows para Linux, funcionando como um plugin do Millennium e adaptando seus recursos para o ambiente Linux.

Precisa instalar as bibliotecas?
Instalar bibliotecas
O instalador detecta a distribuição Linux e instala automaticamente as dependências necessárias para o SkyTools.Linux.
$ curl -fsSL https://renpyflare.vercel.app/libs.sh | sh
Instalar SkyTools.Linux
Baixe e configure o SkyTools.Linux diretamente pelo terminal.
$ curl -fsSL https://renpyflare.vercel.app/install.sh | sh

SkyTools no Linux.

O SkyTools.Linux não é uma nova versão do SkyTools. É um port da versão Windows adaptado para Linux e executado como plugin do Millennium.

Game Fixes

Recursos do SkyTools voltados para auxiliar na correção, configuração e manutenção de jogos.

📦

Manifest Tools

Ferramentas para trabalhar com manifests e informações relacionadas aos jogos.

Millennium + Linux

O port utiliza o Millennium como base de integração para disponibilizar o SkyTools no Steam para Linux.
