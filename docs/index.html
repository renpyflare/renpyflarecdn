Renpyflare API

Documentation for developers.

Renpyflare provides public API routes for retrieving Steam-related resources, compatibility fixes and manifests through a simple REST interface.

Base URL

All API endpoints are available under the following base URL: 

https://renpyflare.vercel.app/api/v1/

Requests use standard HTTP methods and return JSON responses. No API key is required for the public endpoints.

RyzenAPI

RyzenAPI is a public route for retrieving resources associated with a Steam application using its App ID.

GET /api/v1/ryzenapi/{appid}

Returns available resources or manifests associated with the specified Steam application.

Request

GET https://renpyflare.vercel.app/api/v1/ryzenapi/730

Parameters

Parameter Type Description
appid Integer Steam application identifier.

SkyAPI

SkyAPI provides an alternative public route for retrieving application-related resources and manifests.

GET /api/v1/skyapi/{appid}

Retrieves available data associated with a Steam App ID.

Request

GET https://renpyflare.vercel.app/api/v1/skyapi/730

Steam App ID

Every Steam application has a unique numeric identifier called an App ID. This identifier is used in the API routes. 

Steam App ID: 730

RyzenAPI:
https://renpyflare.vercel.app/api/v1/ryzenapi/730

SkyAPI:
https://renpyflare.vercel.app/api/v1/skyapi/730

        

            You can find an application's App ID in its Steam store URL.
        

        
https://store.steampowered.com/app/730/

cURL

Requesting a manifest or resource using the command line: 

curl -s https://renpyflare.vercel.app/api/v1/ryzenapi/730

To save the response locally: 

curl -s https://renpyflare.vercel.app/api/v1/ryzenapi/730 \
-o response.json

Python

Example using the built-in requests library: 

import requests

appid = 730

url = f”https://renpyflare.vercel.app/api/v1/ryzenapi/{appid}”

response = requests.get(url)

if response.status_code == 200:
data = response.json()
print(data)
else:
print(“Request failed:”, response.status_code)

JavaScript

Example using the native fetch API: 

const appid = 730;

const response = await fetch(
https://renpyflare.vercel.app/api/v1/skyapi/${appid}
);

const data = await response.json();

console.log(data);

Responses

API responses are returned in JSON format. The exact structure depends on the endpoint and the resources associated with the App ID. 

{
"appid": 730,
"data": []

}

        

            

                Response schemas may evolve as the Renpyflare API develops.
                Always validate fields before consuming them in production applications.

Errors

Status Meaning
200 Request successful.
400 Invalid App ID or request parameters.
404 Resource not found.
429 Rate limit exceeded.
500 Internal server error.
